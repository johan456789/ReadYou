Each image below is wrapped differently. Tap each one and check the result described above it. Long-press an image for the link menu.

1. Plain image

No link. Tap opens the image viewer.

2. Linked to a larger copy of itself

The "click to enlarge" pattern blogs use. Tap opens the image viewer with the 1600px copy, not the browser.

3. Linked to the same image file

Tap opens the image viewer.

4. Linked to a web page

Like a video thumbnail. Tap opens the link in the browser. Long-press shows the link menu with "View image".
